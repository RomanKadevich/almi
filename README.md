# Праздник призов

Статический адаптивный лендинг на HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` напрямую или запустите любой локальный статический сервер, например:

```sh
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Структура

- `index.html` — семантическая разметка;
- `styles.css` — адаптивы 430/1024/1920 и промежуточные ширины;
- `script.js` — меню, FAQ, карусели, lightbox и данные повторяемых элементов;
- `assets/images` — изображения из Figma;
- `assets/icons` — оригинальные SVG-иконки из Figma;
- `assets/fonts` — локальные web-fonts;
- `assets/docs` — PDF-документы.
