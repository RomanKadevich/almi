# PDF-документы

Положите утверждённые документы в эту папку с именами:

- `rules.pdf` — полные правила рекламной игры;
- `privacy.pdf` — положение о конфиденциальности;
- `terms.pdf` — условия использования;
- `cookies.pdf` — политика cookie.

Ссылки на эти файлы уже подключены в `index.html` и `script.js`.
